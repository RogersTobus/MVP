# 네이버 콘텐츠 스튜디오

네이버 블로그 글을 카테고리별 메모리와 블록형 구조로 생성하고, 검토·수정한 뒤 네이버 작성 화면까지 전달하는 로컬 웹앱입니다.

## 구현된 MVP

- 전체 공통 메모리와 카테고리별 자유 자연어 메모리
- 기본 예시 카테고리 4종
  - 마케팅·경영/MBA 스터디
  - AI·자동화
  - 병원 마케팅
  - 병원·진료 정보
- 10종 블록 추가, 삭제, 드래그 순서 변경, 블록별 지시문
- 글 구조 템플릿 저장과 재사용
- Codex CLI 기반 전체 글 생성 및 블록 단위 재생성
- Codex CLI 이미지 생성 도구를 이용한 대표·본문 이미지 자동 생성
- SQLite 콘텐츠 보관함
- 제목, 요약, 본문 블록 직접 수정과 저장
- 로그인된 Chrome을 통한 네이버 작성 화면 초안 채우기
- 한국어 다크 에디터 UI

## 준비 사항

- Node.js 20 이상
- npm 또는 pnpm
- OpenAI Codex CLI가 설치되고 ChatGPT 계정으로 로그인된 상태
- 네이버 게시 준비 기능을 쓸 경우 Chrome

## 설치와 실행

```powershell
npm install
Copy-Item .env.example .env
npx prisma generate
npx prisma db push
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다. 다른 프로그램이 `localhost`의 IPv6 주소를 사용 중이면 [http://127.0.0.1:3000](http://127.0.0.1:3000)을 사용하세요.

앱을 처음 열면 예시 카테고리와 기본 글 구조가 자동으로 생성됩니다. 데이터베이스 파일은 `data/content-studio.db`에 저장됩니다.

## Codex CLI 연결

1. 터미널에서 Codex CLI 로그인을 완료합니다.
2. 앱의 `설정 → Codex CLI 연결`에서 실행 명령을 확인합니다. 기본값은 `codex`입니다.
3. `Codex 연결 테스트`를 누릅니다.
4. `새 콘텐츠`에서 카테고리, 주제, 템플릿을 선택해 생성합니다.

앱은 다음 정보를 하나의 프롬프트로 조합합니다.

```text
전체 공통 메모리
+ 카테고리 메모리
+ 이번 글 주제와 추가 지시
+ 선택한 글 구조와 블록별 지시
```

Codex는 비대화식 `codex exec`로 호출되며, 앱은 마지막 응답의 JSON을 읽어 SQLite에 저장합니다. 생성 실행은 읽기 전용 샌드박스를 사용합니다. 일반 카테고리는 저장된 지침을 중심으로 작성하고, `병원 마케팅`, `병원·진료 정보`는 웹 검색을 켜 공공 의료기관·관련 학회·대학병원 등 신뢰 가능한 자료를 우선 확인합니다.

의료 글은 핵심 답 → 용어 정의 → 원리 → 비교 → 검사와 판단 요소 → 한계와 주의사항 순으로 충분히 설명합니다. ‘상담받아 보세요’나 병원 홍보가 본문을 대신하지 못하도록 제한하며, 개인 진단이 필요한 부분만 마지막에 짧게 구분합니다.

다른 AI CLI로 바꾸려면 `lib/ai/types.ts`의 `AiAdapter` 인터페이스를 구현하고 `lib/ai/index.ts`의 팩토리에서 선택하면 됩니다.

## 이미지 자동 생성

`메모리`에서 전체 공통 이미지 지침과 카테고리별 이미지 지침을 저장할 수 있습니다. `새 콘텐츠`의 이번 글 이미지 지침은 콘텐츠와 함께 보존되며, 이후 미리보기에서 이미지를 추가 제작할 때도 공통 지침 → 카테고리 지침 → 이번 글 지침 순서로 자동 적용됩니다. 생성 이미지는 `public/generated`에 저장합니다.

`새 콘텐츠`의 레퍼런스 이미지 칸에는 JPG·PNG·WebP·GIF 파일을 최대 5장까지 선택하거나 끌어다 놓을 수 있습니다. 화면 캡처 또는 복사한 이미지는 새 콘텐츠 화면 어디에서든 `Ctrl+V`로 붙여 넣을 수 있습니다. 레퍼런스는 콘텐츠와 함께 저장되며 최초 생성과 미리보기의 추가 이미지 생성에 계속 사용됩니다.

이미지 생성은 API 키를 직접 사용하지 않고 Codex CLI를 통해 실행됩니다. 따라서 로컬 Codex CLI에 `imagegen` 스킬과 이미지 생성 도구가 연결되어 있어야 합니다. 해당 도구가 없는 환경에서는 글 작성 기능은 정상적으로 사용할 수 있지만 이미지 생성 시 연결 안내 오류가 표시됩니다.

설정의 `웹 이미지 레퍼런스 자동 수집`은 기본으로 켜져 있습니다. 이미지 생성 첫 단계에서 로그인된 Chrome 디버깅 세션으로 주제를 네이버 이미지 검색하고, 검색 결과 약 20장을 로컬 임시 후보로 수집합니다. Codex가 후보를 모두 열어 주제 적합성, 실제 사진 여부, 구도 중복, 로고·문구 유무를 비교한 뒤 최대 5장만 생성 레퍼런스로 고릅니다. 선택되지 않은 후보 파일은 즉시 삭제합니다. 실제 방문자 수를 알 수 없으므로 검색 상위 노출을 트래픽의 대리 지표로 사용합니다. 원본 이미지를 게시하거나 복제하지 않고 새 이미지의 피사체·구도·색감 참고에만 사용하며, CAPTCHA나 보안 확인이 나타나면 수집을 중단합니다.

선정된 웹 레퍼런스는 콘텐츠 미리보기의 `적용 중인 레퍼런스와 출처`에서 출처 도메인, 출처 페이지, 원본 이미지 링크를 확인할 수 있습니다. 직접 붙여 넣은 이미지는 `사용자 제공`으로 구분합니다. 이전 버전에서 수집되어 주소 정보가 남아 있지 않은 이미지는 `출처 미기록`으로 표시합니다.

자동 수집 원본은 저작권 문제를 피하기 위해 GitHub에 저장하지 않습니다. 다른 PC에서는 이미지 생성 시 해당 주제를 다시 검색해 레퍼런스를 채웁니다.

## GitHub 백업과 다른 PC에서 이어서 사용하기

이 프로젝트는 코드와 함께 `data/content-studio.db`, 생성 이미지, 사용자가 직접 넣은 레퍼런스를 저장소에 보관하도록 구성합니다. `.env`, 로그인 정보, Chrome 세션, 자동 수집한 웹 원본은 저장하지 않습니다.

다른 Windows PC에서 이어서 사용할 때는 저장소를 받은 뒤 다음을 실행합니다.

```powershell
git clone https://github.com/RogersTobus/MVP.git
cd MVP
corepack enable
pnpm install
Copy-Item .env.example .env
pnpm exec prisma generate
pnpm run dev
```

Codex CLI 로그인과 Chrome 디버깅용 네이버 로그인은 PC마다 한 번씩 별도로 진행해야 합니다. 작업공간 변경 후에는 검사 → 커밋 → `origin` 푸시를 수행하도록 `AGENTS.md`에도 프로젝트 규칙을 남겨 두었습니다.

## 네이버 게시 준비

이 MVP는 사용자의 정상 로그인 세션을 사용하기 위해 Chrome 원격 디버깅 연결 방식을 씁니다. 기존 Chrome을 모두 종료한 뒤 별도 프로필로 Chrome을 여는 예시는 다음과 같습니다.

```powershell
Start-Process "C:\Program Files\Google\Chrome\Application\chrome.exe" -ArgumentList "--remote-debugging-port=9222", "--user-data-dir=$env:LOCALAPPDATA\NaverContentStudioChrome"
```

1. 열린 Chrome에서 네이버에 정상 로그인합니다.
2. 앱 설정에 블로그 ID와 `http://127.0.0.1:9222`를 저장합니다.
3. 콘텐츠 보관함에서 `게시 준비`를 누릅니다.
4. 앱이 새 글 작성 화면에 제목과 본문 초안을 채웁니다.
5. 사용자가 내용을 최종 확인하고 네이버의 게시 버튼을 직접 누릅니다.

## 게시 자동화의 한계와 주의사항

- 최종 게시 버튼은 자동으로 누르지 않습니다.
- CAPTCHA, 자동입력 방지, 추가 인증, 보안 확인은 우회하지 않습니다. 감지되면 자동화가 멈춥니다.
- 네이버 스마트에디터의 화면 구조가 바뀌면 자동 입력 선택자를 조정해야 할 수 있습니다.
- 최초 로그인, 약관 동의, 본인 확인은 사용자가 직접 처리해야 합니다.
- 의료 콘텐츠는 의료광고 관련 법규와 기관 내부 검수 기준을 별도로 확인해야 합니다.
- 생성된 사실, 수치, 후기, 치료 정보는 발행 전에 반드시 사람이 검토해야 합니다.

## 주요 폴더

```text
app/                 화면과 서버 요청 처리
lib/ai/              교체 가능한 AI CLI 어댑터
lib/publishers/      네이버 게시 준비 어댑터
prisma/              SQLite 데이터 모델
data/                로컬 데이터베이스 파일
```

## 배포 빌드 확인

```powershell
npm run build
npm run start
```

이 앱은 로컬 로그인 세션과 CLI를 사용하므로 일반적인 서버리스 호스팅용이 아닙니다. 한 PC에서 `localhost`로 사용하는 것을 전제로 합니다.
